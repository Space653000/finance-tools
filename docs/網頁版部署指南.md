## 為什麼這條路對

你決定放棄 App Store，改走網頁。這個判斷是對的，理由不是「比較簡單」，而是**成本結構完全不同**：

| | App Store | 網頁 |
|---|---|---|
| 硬體 | **必須有 Mac**（Xcode 只跑 macOS） | 任何電腦都行 |
| 年費 | US$99，斷繳 App 下架 | 0 |
| 審核 | 每次更新都要送審 | 推上去就生效 |
| 改一個字 | 重新打包、送審、等 1–2 天 | 推上去，30 秒後全世界看到 |
| 自然流量 | 幾乎沒有，商店搜尋被大廠佔滿 | **Google 搜尋，這是你的主戰場** |
| 分享 | 要對方去商店下載 | 貼一個連結就行 |

**最關鍵的是最後兩項。** 你的內容優勢（質押、維持率、房貸、FIRE）都是**有人在 Google 上搜尋的東西**。網頁能吃到這些流量，App 吃不到。

而且 PWA 讓使用者可以把網頁加到手機主畫面，圖示、全螢幕、離線可用——**體感上就是一個 App，只是不用經過任何人審核。**

未來如果流量夠大、真的需要上架，再把同一份程式碼包成 App 也不遲。反過來就難了。

## M2　Git 與 GitHub

Git 是版本控制，GitHub 是放程式碼的地方。這兩個是後面全部自動化的地基。

### 2-1　安裝 Git

**Windows**：到 git-scm.com 下載安裝程式，一路下一步。
**macOS**：終端機輸入 `git --version`，沒裝的話系統會自己問你要不要裝。

安裝後設定身分（這會出現在每次提交紀錄裡）：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的信箱"
```

### 2-2　建立 GitHub 帳號與儲存庫

1. 到 github.com 註冊
2. 右上角 `+` → New repository
3. Repository name 填 `finance-tools`（或你想要的名字）
4. 選 **Public**（要讓 Google 搜尋得到；Private 也能部署，但沒必要）
5. **不要**勾選 Add a README（我們已經有了）
6. Create repository

### 2-3　把專案推上去

在專案資料夾裡：

```bash
git init
git add .
git commit -m "M1：專案初始結構與複利模擬器基準版"
git branch -M main
git remote add origin https://github.com/你的帳號/finance-tools.git
git push -u origin main
```

第一次推送會要你登入。GitHub 現在不接受密碼，會跳出瀏覽器授權，照著做就行。

### 2-4　之後每次改東西

```bash
git add .
git commit -m "說明你改了什麼"
git push
```

三行。Cloudflare 會自動抓到並重新部署。

## M3　Cloudflare Pages

### 3-1　連結

1. 到 dash.cloudflare.com 註冊
2. 左側選 **Workers & Pages** → Create → Pages → **Connect to Git**
3. 授權 GitHub，選擇你的 `finance-tools` 儲存庫
4. 建置設定：

| 欄位 | 填什麼 |
|---|---|
| Framework preset | **None** |
| Build command | **留空** |
| Build output directory | **`/`**（根目錄） |

**因為我們是純靜態檔案，沒有建置步驟。** 這是原生 HTML 架構的好處之一——沒有東西會建置失敗。

5. Save and Deploy

約一分鐘後你會拿到一個網址，像 `finance-tools-abc.pages.dev`。**打開它，你的工具已經在線上了。**

### 3-2　之後的更新流程

```
你改檔案 → git push → Cloudflare 自動偵測 → 約 30 秒後上線
```

不用做任何事。這就是「修改一次，全世界同步更新」。

## M4　網域

`.pages.dev` 的網址能用，但不好記也不專業。

### 4-1　買網域

在 Cloudflare Registrar 買最省事（它是成本價，沒有第一年低價第二年跳漲那套）。也可以用其他註冊商再把 DNS 轉過來。

命名建議：

| 型態 | 例子 | 適合 |
|---|---|---|
| 個人品牌 | `stephen.tw` | 你用真名，這很合理 |
| 工具站 | `tools.你的網域` | 主打功能 |
| 主題 | `finance.你的網域` | 主打領域 |

`.tw` 對台灣搜尋略有加分，`.com` 較通用。**先想好，之後換網域會丟掉累積的 SEO。**

### 4-2　綁定

Cloudflare Pages 專案 → Custom domains → Set up a custom domain → 輸入網域。

如果網域也在 Cloudflare，會自動設定好。HTTPS 憑證自動申請、自動續約，你什麼都不用做。

**記得同時設定 `www` 導向主網域**（或反過來），不要讓兩個網址都能開同一個網站，那會分散 SEO 權重。

## M5　PWA（讓網頁變成手機 App）

這一步之後，使用者在 iPhone Safari 開你的網站 → 分享 → 加入主畫面 → 桌面出現圖示 → 點開是全螢幕，沒有網址列。

**看起來就是 App。** 但不用審核、不用年費、不用 Mac。

需要的檔案（都是新增，不動既有程式）：

- `manifest.json` — 名稱、圖示、主題色、顯示模式
- `sw.js` — Service Worker，讓網站可離線使用
- 圖示 192×192 與 512×512 PNG

唯一需要動到既有頁面的，是在 `<head>` 加三行 link/script。**這會事先提出方案給你確認。**

## M6　SEO（你最重要的獲客管道）

網頁相對 App 的最大優勢就在這裡。要做的事：

| 項目 | 做什麼 |
|---|---|
| 頁面 meta | title、description，每頁不同 |
| Open Graph | 分享到 LINE、FB 時的預覽卡片 |
| sitemap.xml | 告訴 Google 有哪些頁面 |
| robots.txt | 允許收錄 |
| 結構化資料 | 標記為工具類網頁 |
| Google Search Console | 提交網站、看關鍵字表現 |

**真正帶來流量的是內容。** 寫幾篇文章，例如：

- 股票質押維持率怎麼算，跌多少會被追繳
- 理財型房貸拿去投資，真實成本是多少
- 定期定額二十年，內扣費用會吃掉你多少錢

每篇文末連到對應工具。這是最便宜也最持久的獲客方式，而且**這些正好是你本來就懂的東西**。

## 一件仍然要做的事

放棄 App Store 不代表法規風險消失。**網站一樣是對公眾提供財務試算服務。**

上線前請確認：

1. 免責聲明在每個工具頁面都看得到（目前的模擬器已內建）
2. 站上不出現任何預測值、投資建議、標的推薦或方案排名
3. 若未來要收費或做會員，屆時再諮詢執業律師

好消息是：因為全部本地計算、不蒐集個資、不上傳財務資料，**你連隱私權政策都可以寫得很短而且是誠實的**。這在同類網站裡反而是稀有的賣點。
