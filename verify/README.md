# 獨立驗證機制

驗證的不是「程式看起來對不對」，而是**四個彼此獨立的來源算出來是否一致**。

| # | 來源 | 獨立性 |
|---|---|---|
| 1 | `harness.js` | 直接載入 `tools/compound/index.html` 的 `<script>`，**測的是上線的那份程式**，不是副本 |
| 2 | `independent.py` | 不參考 JS，依金融數學公式重新實作 |
| 3 | `compare.py` 內的封閉解 | 年金公式、複利封閉解、手算值 |
| 4 | `verification_workbook.xlsx` | **Excel 原生財務函式**（PMT／FV／IPMT／PPMT）由 Excel 自己算 |

四個來源若一致，錯誤同時發生在四處的機率極低。

## 怎麼跑

**Windows**：連點兩下 `run.bat`

> 若視窗一閃即關，代表 Node.js 或 Python 尚未安裝。
> 請先安裝 [Node.js LTS](https://nodejs.org) 與 [Python 3](https://www.python.org/downloads)（安裝時務必勾選 **Add python.exe to PATH**），裝完重開 `run.bat`。
> 或在 verify 資料夾的路徑列輸入 `cmd` 按 Enter，再輸入 `run.bat`，即可看到完整訊息不會閃退。
**macOS / Linux**：終端機執行 `./run.sh`

需要先安裝 [Node.js](https://nodejs.org)（選 LTS）與 [Python 3](https://www.python.org/downloads)（安裝時勾選 Add to PATH）。

跑完會產生 `report.txt`。

## 還要做一件事

開啟 `verification_workbook.xlsx`。裡面的儲存格填的是 Excel 公式，**Excel 會自己重算一次**，看「判定」欄是否全部顯示 ✅。

這一步不能省——前三個來源都是我寫的，Excel 是唯一完全不受我影響的第三方。

## 驗證規模

| 層次 | 內容 | 數量 |
|---|---|---|
| 定點測試 | 逐項比對已知情境 | 39 項數值 + 17 項封閉解 + 8 項性質 |
| **大規模掃描** | 系統列舉 + 亂數取樣 + 邊界值 | **11,084 組案例、約 158,000 個比對點** |
| 不變量 | 與實作無關、數學上必須成立的恆等式 | 7 類，逐案檢查 |
| 第三方 App 對照 | 房貸小幫手（500 萬 / 2.8% / 20 年 / 寬限 3 年） | 3 項 |
| Excel | 原生 PMT / FV / IPMT / PPMT | 需你手動開啟確認 |

大規模掃描的組合覆蓋：

- **3 種投資模式** × **6 種借款類型** × **4 種還款方式** × **有無寬限期** × **借款是否投入市場** = 216 類，每類 3 組參數
- **2,200 組多筆借款疊加**（每組隨機 2–4 筆，類型、金額、利率、年期、還款方式皆隨機）
- **8,200 組純參數掃描**（本金、月投、年期、報酬、標準差、通膨、複利頻率、配息、費用、課稅方式、稅率級距、二代健保、收入、現金、調升率全部隨機）
- **144 組極端邊界值**（零本金、零報酬、零利率、最短最長年期、最高最低標準差）

## 檢查了什麼

- 攤還：本息平均、本金平均、按期付息、寬限期
- 逐期拆分：首期利息、首期本金、12 期後餘額
- 複利：單筆、定期定額、混合，五種複利頻率
- 費用與稅：內扣總費用、股利所得稅、二代健保補充保險費
- 擔保：維持率、距離追繳、距離處分、現金可支應月數
- 蒙地卡羅：可重現性、百分位排序、標準差為零時收斂至確定性路徑
- 邊界輸入：零本金、零報酬、零利率
- 恆等式：首期利息＋本金＝月付金、複利頻率越高月報酬越高

## 回傳

把 `report.txt` 與 Excel 判定欄的結果回傳即可。
